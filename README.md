# 🔍 Пошук аномалій, Ризиків та Інсайтів у High-Dimensional Supply Chain Inventory Dataset

**Авторський аналітичний проєкт** *Проєкт присвячений глибокому аудиту логістичних ланцюгів та фінансових витоків через наскрізний аналіз взаємозв'язків між продажами, рівнями запасів (Overstock/Critical) та надійністю постачальників.*

---

### 📌 Ключові виміри аналізу (High-Dimensionality):

* **Inventory & Capital Optimization:** Оцінка замороженого капіталу в надлишках та ризиків дефіциту (Stockout).
* **Supplier Lead Times:** Статистичне моделювання надійності логістичних буферів.

## 🕵️‍♂️ Кейс Data Quality Assurance: Пастка неагрегованих обчислень та сліпого переносу коду

Найважливішим інженерним результатом проєкту став повний перегляд ранніх висновків через виявлення помилки розрахунку гранулярності даних (Data Grain).

**❌ Помилковий підхід (Сліпий перенос із коду в BI):**
Первинно метрику ефективності складів (`warehouse effective`) було перенесено прямолінійною рядковою формулою: `[Profit] / [Inventory_Level]`.
* **У чому пастка:** Оскільки формула не містила вбудованих агрегацій, Tableau виконав ділення для кожного окремого транзакційного рядка, а на етапі візуалізації автоматично застосував функцію **`SUM`** до цих часток (`SUM(warehouse effective)`).
* **Математичний шум:** Математика перетворилася на «суму часток», штучно роздуваючи показники складів із великою кількістю транзакцій. Склад **WH_1** помилково визнали аутсайдером із критичним відставанням у **$827.8** від лідера.

**✅ Правильний інженерний підхід: Спочатку агрегація — далі візуалізація:**
Логіку було переписано у вигляді чіклого фінансового коефіцієнта: `SUM([Profit]) / SUM([Inventory_Level])`. Позначка **`AGG`** у Tableau зафіксувала контекст обчислень: система спочатку згрупувала весь прибуток, потім усі залишки, і лише наприкінці виконала ділення.

Паралельно було впроваджено жорстку модель щоденного аудиту втрат та оцінки **замороженого капіталу (Overstock)**:
```tableau
IF [Inventory_Level] > ([Demand_Forecast] * 1.5) 
THEN ([Inventory_Level] - [Demand_Forecast]) * [Unit_Cost] 
ELSE 0 END
